Импорт из CSV

Используйте Exportify для экспорта плейлиста Spotify в файл .csv.

Используйте TuneMyMusic для экспорта плейлиста Apple Music в .csv.
(Импорт из Apple Music иногда содержит неточности)

Вставьте ссылку на плейлист YouTube Music.

Заголовки столбцов в файле должны быть на английском языке.

Строгое совпадение альбомов Название альбома должно точно совпадать с CSV. Отключите для лучшего поиска.

Импорт из JSPF

JSPF (JSON Shareable Playlist Format) поддерживается многими плеерами и хранит метаданные включая идентификаторы MusicBrainz.


Импорт из XSPF

XSPF (XML Shareable Playlist Format) — стандартный формат плейлистов XML для VLC, Audacious и Clementine.


Импорт из XML

Импорт плейлистов из XML-файлов iTunes, Winamp и других плееров.


Импорт из M3U/M3U8

Универсальный формат плейлистов. Данные треков считываются из расширенного M3U.


Внимание: автоматический подбор не гарантирует 100% точность. Проверьте список треков после импорта.

Публичный плейлист Доступен всем, у кого есть ссылка.

Редактировать профиль

Интеграция Last.fm отображает недавние скробблы и статистику в профиле. Подключите в разделе Настройки > Скробблинг. Авторизация хранится локально на каждом устройстве.

    Графический эквалайзер
    
                                            
      
                                                
    1. Укажите число полос (3–32) и диапазон частот (Min/Max Гц).
      2. 
                                                
    2. Двигайте ползунки для усиления или ослабления частотных полос.
      3. 
                                                
    3. Выберите базовый пресет — он масштабируется под число полос.
      4. 
                                                
    4. Регулируйте Preamp, чтобы избежать перегруза при подъёме частот.
      5. 
                                                
    5. Сохраняйте свои пресеты и используйте экспорт/импорт EqualizerAPO или CSV.
      6. 
                                            
    
                                            
    Совет: лучше ослаблять лишние частоты, чем задирать остальные — так меньше клиппинга.
    
                                        
    

                                        
    
                                            
    AutoEQ — коррекция наушников
    
                                            
      
                                                
    1. Выберите модель наушников из базы или импортируйте замер.
      2. 
                                                
    2. Укажите целевую кривую (Harman, Diffuse Field и др.).
      3. 
                                                
    3. Задайте число фильтров (10 — оптимально) и нажмите AutoEQ.
      4. 
                                                
    4. Перетаскивайте узлы на графике; колесо мыши меняет добротность Q.
      5. 
                                                
    5. Правый клик по узлу переключает тип фильтра и режим Stereo / Mid / Side.
      6. 
                                            
    
                                            
    Совет: включите автокомпенсацию Preamp для защиты от искажений.
    
                                        
    

                                        
    
                                            
    Параметрический эквалайзер
    
                                            
      
                                                
    1. Фильтры Peaking, Low Shelf, High Shelf с настройкой частоты, усиления и Q.
      2. 
                                                
    2. Перетаскивайте узлы на графике; прокрутка меняет ширину полосы Q.
      3. 
                                                
    3. Правый клик по узлу задаёт канал: Stereo, Mid или Side.
      4. 
                                                
    4. Двойной клик по пустому месту добавляет узел, по существующему — удаляет.
      5. 
                                                
    5. Доступен импорт и экспорт в формате EqualizerAPO.
      6. 
                                            
    
                                            
    Совет: ниже Q — шире колокол; выше Q — точечная коррекция резонансов.
    
                                        
    

                                        
    
                                            
    Коррекция акустики помещения
    
                                            
      
                                                
    1. Выберите конфигурацию (2.0, 5.1 или 7.1) и нужный канал.
      2. 
                                                
    2. Измерьте комнату розовым шумом или импортируйте файл замера REW.
      3. 
                                                
    3. Задайте границы Bass Limit и Room Limit и нажмите AutoEQ.
      4. 
                                                
    4. Подправьте фильтры вручную и экспортируйте профиль в JSON.
      5. 
                                            
    
                                            
    Совет: размещайте микрофон в точке прослушивания отдельно для каждой колонки.

            О FlacLess
            
                    
            
                        
            
                            FlacLess — лёгкий и приватный клиент для стриминга и загрузки музыки в Hi-Res FLAC без потерь на iOS и в браузере. Без рекламы, подписок и лишних элементов.
                        
            
                        
            
                            
                                Telegram: @rvkqq
                            
                            
                        
            
                        
            
                            
            Версия 2.5.1 (FlacLess iOS / Web)
            
                            
            
                            
            
                                Независимое приложение, не связанное с какими-либо стриминговыми сервисами.
                            
            
                            
            
                                Приложение не хранит и не распространяет медиафайлы на собственных серверах. Все данные загружаются напрямую из публичных сторонних API-узлов.
                            
            
                        
            
                    
            
                
            
                
            
                    
            Вход и синхронизация
            
                    
            
                        
            
                            Создайте аккаунт, чтобы синхронизировать медиатеку и плейлисты между устройствами.
                        
            
                        
            
                            
                            
                            
                            
                            
                        
            

                        
            
                            Синхронизация медиатеки между устройствами
                        
            
                        
            
                            Сохраняются только данные медиатеки и анонимный идентификатор синхронизации.
                            
            
                            Никакой рекламы и лишнего сбора данных.
                        
            
                        
            
                            При желании вы можете указать собственный сервер PocketBase и OAuth.
                        
            
                        
            
                            Дополнительно: свой сервер
                        
            
                    
            
                
            
                
            
                    
            
                        
            
                            FlacLess для iOS (.ipa)
                        
            
                        
            
                            Соберите чистый файл .ipa прямо в своём репозитории GitHub (без Mac и без рекламы) для установки через AltStore, SideStore, Sideloadly, ESign, Feather или TrollStore.
                        
            
                        
            
                            
                            
                                Telegram: @rvkqq
                            
                        
            
                        
            
                            Поддержка нативного фонового аудио AVAudioSession, Lock Screen, Dynamic Island и 120 Гц ProMotion включена в сборку автоматически.
                        
            
                        
            
                            Скачанные треки сохраняются в папку Файлы / FlacLess (или Downloads/FlacLess) на устройстве.
